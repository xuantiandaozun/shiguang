# 桌面整理

这是应用自带、可编辑的外部技能。分类习惯统一写在本文，不依赖应用内部规则库。

## 操作步骤

1. 调用 discover_capabilities 加载 organize 能力，再 scan_desktop 获取实际文件。
2. 按下方用户偏好制定方案；不确定的文件保留原位，不为普通分类逐项询问。
3. 使用 propose_organization 提交方案，等待专用方案卡确认，不重复 ask_user。
4. 文件名使用桌面顶层项的 name；分类只用单层文件夹名，已有收纳文件夹保持原位。
5. 不删除文件；快捷方式、隐藏项与系统文件默认不移动。重名不覆盖，必要时先核实。
6. 用户要求「以后这样整理」时，load_skill 读取本技能全文，用 create_skill 更新同名技能，保留其他内容。分类偏好是建议，不是未来危险操作的永久授权。

## 用户分类偏好

- 文档、表格、演示文稿、图片、视频、音频、压缩包、安装包、代码项目按用途分类。
- 文件名能明确识别项目时，可按项目合并分类。
- 用户后续明确要求的偏好记录在此。
