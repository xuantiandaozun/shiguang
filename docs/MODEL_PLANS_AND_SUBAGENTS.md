# 模型套餐与子代理

每个供应商配置独立保存接口地址、密钥、手动添加的模型列表和可选到期时间。当前模型及子代理模型只从对应配置的列表选择；模型名称按接口要求填写，显示名称、视觉能力和上下文窗口可以分别设置。旧配置自动迁入当前使用的模型，不替换供应商模型名称。

到期时间按本机时区解释。留空表示不限制有效期；到期后主对话、外部委托和子代理在下一次模型调用前停止，提示切换配置或续期。已经发出的请求不会被撤回。续期后可在原任务中继续。未选中的过期配置仍可保存和编辑。

阿里 Coding Plan 预设使用国内 OpenAI 兼容接口 `https://coding.dashscope.aliyuncs.com/v1`，模型列表由用户按实际套餐手动添加。接口依据：[阿里云官方接入说明](https://help.aliyun.com/zh/model-studio/other-tools-token-plan)。

## 常用子代理

| 角色 | 任务范围 | 配置 |
| --- | --- | --- |
| 资料调研 | 多步公开资料检索与分析，输出证据和结论 | 跟随主配置或独立供应商、模型 |
| 文件分析 | 指定文件与目录范围的阅读分析 | 跟随主配置或独立供应商、模型 |
| 浏览器操作 | 网页操作、流程执行与页面验收 | 跟随主配置或独立供应商、模型 |

三个角色可分别启停。主代理根据任务自动使用已启用角色；简单单步任务直接完成。主代理应传入准确目标、环境、上下文、允许及排除范围、产出路径、证据要求和少量关键节点。子代理不能再次委托。

浏览器子代理沿用委托任务的状态与记录，在关键节点暂停并回传证据。主代理通过 `await_subagent` 等待节点，再用原 `job_id` 的 `reply_subagent` 审核或纠偏，继续同一任务。用户补充信息由用户回答。阶段内部自主执行，无须实时监控。浏览器执行阶段排队使用共享浏览器，主代理也应避免同时操作该浏览器。

浏览器角色允许浏览器操作、任务产物读写、技能、待办和节点回传，禁止任意命令及全盘文件搜索。资料与文件角色保持只读，文件角色不使用公开网页检索。主任务取消会取消浏览器子任务。

供应商切换、模型删除或配置删除时，失效的子代理选择回到跟随对应配置，避免沿用另一家供应商的模型名。旧动态工具注册表在运行时补齐角色参数，保留用户自定义描述和存储记录。

验证：Rust 单元测试、前端迁移/过期/供应商隔离检查和前端生产构建。当前环境浏览器测试运行时启动失败，尚未进行真实界面交互和在线模型调用验证。
