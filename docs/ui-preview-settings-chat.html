本轮方案梳理（确认前不改源码）

A 桌面整理降级为 Skill

问题：整理是早期主功能，但顶栏「整理规则 / 操作记录」与聊天主路径重复，宣传时产品线过长。

方案：

  • 能力仍在：扫描 / 方案卡 / 执行 / 撤销 / 自动规则 —— 不删后端。
  • 体验改口：对用户呈现为内置 Skill「桌面整理」；聊天命中时 load_skill。
  • 顶栏去掉「整理规则」「操作记录」；两者作为 Skill 管理页的子入口（见「信息架构」页）。
  • 自动整理开关可挪到该 Skill 管理页或设置 P2，不再和模型配置抢首屏。

B 设置层级与优先级

层级内容展示
P0聊天模型配置、操作权限（平衡/谨慎/高效）默认展开，置顶
P1图像识别/OCR、系统（开机启动/更新）展开，次之
P2 高级智能加速 System One、命令工具、个人资料、上下文压缩、临时目录清理默认折叠

原则：先能聊、少打断；再看图；专家项进高级。避免「智能加速」大卡片压过模型与权限。

C 图标策略（含命令窗）

  • 统一 24 坐标线性图标族，currentColor，选中用琥珀浅底，不给每个按钮不同彩色。
  • 命令窗现状全是文字（最大化、显示文件列表、AI 模式、Tab 补全、清屏、断开、上传、刷新、上级、发送、停止）→ 工具栏改为图标；确认类危险操作保留文字。
  • 主窗口顶栏可「图标+短标签」；聊天顶栏图标 only。
  • 实现时优先项目内 SVG / 技能库 CC0 图标，不引入沉重 iconfont 运行时。
