# 拾光 v0.1.5

本次更新重点完善服务器管理、AI 运维对话和远程文件操作。

## 服务器与终端

- 新增 SSH 连接管理，支持密码、私钥、SSH Agent、主机指纹核对，以及通过拾光 AI/MCP 查询、新增、修改和删除连接。
- 独立交互终端保留当前目录和 Shell 状态，支持窗口最大化/还原及尺寸自适应。
- 右侧远程文件列表支持目录跳转、筛选、刷新和 UTF-8 文本预览；可隐藏、调整宽度，并按服务器记住显示偏好。
- 同目录刷新改为后台更新，不再因 AI 执行命令而禁用目录操作；重复请求合并，自动刷新不会打断目录切换。

## AI 运维对话

- AI 模式下左侧完整切换为聊天界面，由 AI 在后台输入命令、读取执行结果并总结，支持连续追问；退出自动清屏恢复手动终端。
- 风险判断按实际影响分类：正常只读查询、日志筛选、管道和普通项目文件操作默认自动执行，敏感或破坏性操作才请求确认。
- 精简上下文：执行期间只传当前步骤必要输出并滚动提炼摘要；任务结束后保留结论、相关路径、检查时间和未完成事项，不跨轮堆积原始日志与命令回显。
- 已确认事实与推测分开记录，服务、进程和端口等易变状态按需复查，不直接将旧摘要当作实时结果。

## 文件传输与其他改进

- 支持多选文件上传，显示传输状态、已传输字节数及取消操作；同名覆盖或敏感位置写入需确认。
- 终端 AI 可使用用户提供的本机文件路径发起 SFTP 上传，确认来源和目标、等待上传完成后继续后续操作。
- 完善 SSH/SFTP 共用工具与本地 MCP 接入、图片读取，并优化辅助程序构建。

## 使用与安全提示

- 请下载下方 Windows x64 安装包；已安装拾光的用户也可在设置中检查更新。
- 首次连接或主机指纹变化仍需人工核对确认。删除连接只删除本机连接和凭据，不删除远程服务器及其文件。
- 已保存的连接密码和私钥口令以明文存于本机数据库，请妥善保管。操作目标、必要执行结果及用户提供的本机路径会发送给已配置的模型，上传文件本体不会发送给模型。
- 关闭终端不保证远程进程停止；取消目录上传时，已完成的文件可能仍然保留。全屏 TUI 请在命令模式运行。

验证：前端生产构建、196 项 Rust 库测试、终端上下文/文件刷新回归测试及本机回环 SSH/SFTP 集成测试通过；真实服务器与在线模型组合的兼容性仍需结合使用环境验证。
